How to Run Agents in Production

The eight pillars of running agents as governed digital employees in a regulated bank — the half of the job the "how to build an agent" guides leave out.

Build-guides stop at "it works on my machine." A bank ships only when it can answer three questions in writing: what's the worst this agent can do, who reviews it, and how do we turn it off. This poster is those answers, on one page.
